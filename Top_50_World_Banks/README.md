# Largest Banks Data Analysis Project

#Project Overview

This project uses Python to extract, clean, analyze, and visualize data on the world's largest banks. The data was originally stored in a PDF file and was converted into a CSV file using the Tabula library. After extracting the data, I used Pandas to clean the dataset by removing unnecessary columns, handling duplicates, and preparing the data for analysis.

# Technologies Used in This Project

* Python
* Pandas
* Tabula
* Numpy
* Matplotlib

# What This Project Does

* Extracted bank data from a PDF file and converted it to CSV format.
* Cleaned and organized the dataset using Pandas.
* Removed duplicate records and unnecessary columns.
* Converted and formatted asset values for analysis.
* Sorted banks by total assets.
* Created a Matplotlib bar chart showing the 15 largest banks in the world by assets.

# Skills Learned in This Project

This project helped me practice data extraction, data cleaning, data analysis, and data visualization using Python. It also strengthened my understanding of working with real-world datasets and preparing data for reporting and business insights.
