# Top 10 Largest Economies – Data Engineering Project / Coursera

#Project Overview

In this project, I worked as a junior Data Engineer for a simulated international firm expanding globally. The goal was to extract and analyze the top 10 largest economies in the world based on GDP data published by the International Monetary Fund (IMF).

#What This Project Does

* Extracts GDP data directly from a Wikipedia page (archived link) using Pandas

* Selects and cleans the required table

* Filters the top 10 countries by GDP

* Converts GDP values from Million USD to Billion USD

* Rounds values to 2 decimal places using NumPy

* Visualizes the results using Plotly Express with an interactive bar chart

# Tools & Technologies

*Python

* Pandas (Web scraping & Data Cleaning)

* NumPy (Data transformation & rounding)

* Plotly Express (Data Visualization)

# Key Skills Gained

* Web data extraction using pd.read_html()

* Data cleaning and transformation

* Data type conversion and column manipulation

* Real-world data engineering workflow
